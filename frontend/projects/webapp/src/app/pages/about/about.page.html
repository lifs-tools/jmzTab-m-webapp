About the mzTab-M Validator

A web service of the LIFS Tools Consortium that checks mzTab-M files for structural and semantic correctness.

mzTab-M and jmzTab-m

mzTab-M is the HUPO-PSI tab-separated exchange format for quantitative results of mass spectrometry based metabolomics experiments. jmzTab-m is its Java reference implementation; this service uses it to parse and validate your files.

mzTab 1.0 validation was retired in version 2.0.0.

Validation levels

The level decides which messages are reported:

  • INFO everything, including hints that need no action.
  • WARN warnings and errors.
  • ERROR only errors that make the file invalid.

Validation profiles and mapping files

A validation profile defines which controlled vocabulary terms, cardinalities and rules are expected in addition to the structural checks. Choose one of the profiles offered on the start page, for example the default mzTab-M 2.0 profile.

Semantic checks look up controlled vocabulary terms in the EBI Ontology Lookup Service (OLS), so validation needs network access to EBI OLS and may take longer for large files.

Retention and privacy

Uploaded files and validation results are @if (info()?.retentionDays; as days) { kept for {{ days }} days } @else { kept for a limited time } and then deleted. You can delete a result earlier on its result page. Anyone who has the address of a result can open it, so share it with care.

With your consent, this site uses Matomo to count page views. Page views are counted only after you agree, and addresses of results are never sent. You can change your choice any time using Analytics in the page footer.

Separately, when analytics is configured, the server counts validations anonymously: no file names, no file contents and no identifiers are sent.
