@switch (chapter) { @case ('overview') {

An mzTab-M file is a plain text file in which the fields of a line are separated by tabs. The first field of every line says what the line is, and the lines that belong together form one of four sections.

MTD
The metadata: what the file is, how the data was measured and which samples, runs and assays it covers.
SMH, SML
The summary: a header line and one row for each molecule that the study reports, here each lipid.
SFH, SMF
The features: a header line and one row for each measured signal behind a molecule.
SEH, SME
The evidence: a header line and one row for each identification of a molecule.
COM
A comment. Comment lines explain the file to a reader and carry no data; empty lines separate the sections.

The pages of this chapter walk through one small lipidomics file, section by section. It reports two lipids, a ceramide and a phosphatidylcholine, in the plasma of a control and a treated individual. The other pages of this chapter show the lines of that file that each step is about, with the tabs drawn as arrows. The differences between mzTab-M 2.0 and 2.1 are described under mzTab-M 2.0 and 2.1.

} @case ('metadata') {

The metadata section holds the lines that start with MTD. Each has the form MTD, a key and a value.

Many keys repeat with a number in square brackets, such as sample[1] and sample[2], and the part of the key before the bracket names a group of related lines. Lines of one group describe one thing: assay[1]-sample_ref and assay[1]-ms_run_ref both describe the first assay. The steps below go through the groups of the teaching file in the order a reader needs them: what the file is, how the data was measured, how samples, runs and assays belong together, and which groups are compared.

} @case ('summary') {

The summary section reports the result of the study: one row for each molecule, here each lipid.

The header line (SMH) names the columns and each row (SML) fills them. Besides the name and the identifiers of the lipid, the row holds its abundance in every assay and in every study variable that the metadata declares.

} @case ('features') {

The feature section lists the measured signals behind the molecules of the summary.

The header line (SFH) names the columns and each row (SMF) describes one signal: the mass-to-charge ratio, the charge, the retention time and the abundance in each assay. A molecule can rest on several features, for example a precursor ion and its fragment ions, and a feature can point to the evidence that identifies it.

} @case ('evidence') {

The evidence section holds the identifications: what a signal was matched to and how confident the match is.

The header line (SEH) names the columns and each row (SME) describes one identification, with the spectrum it was made from, the measured and the theoretical mass, and one or more confidence measures.

} @case ('references') {

The rows of the three tables and the lines of the metadata refer to each other by number.

A summary row lists its features in the column SMF_ID_REFS, a feature lists its evidence in SME_ID_REFS, and the abundance columns refer to assays and study variables that the metadata declares. A reference to something that does not exist is an error, which is why the validator checks them.

} @case ('cv-parameters') {

Most values that describe the measurement are parameters from a controlled vocabulary, so that tools can read them without guessing.

A parameter has four fields in square brackets: [CV label, accession, name, value]. The label names the vocabulary, the accession and the name identify one of its terms, and the value is only filled when the term needs one. Every label that a parameter uses is declared once with the cv[n] lines of the metadata.

} @case ('study-design') {

mzTab-M 2.1 can describe the design of a study: the factors that were varied and the levels of each.

This page uses a different teaching file, a 2.1 file with two factors, sex and timepoint, that crosses two sexes with three timepoints. A study variable group is a factor, its study variables are the levels, and each assay is one cell of the design. The file has metadata and a summary only, and its profile, M+S, says so.

} }
