Converting a 2.0 file to 2.1

  1. Change mzTab-version from 2.0.0-M to 2.1.0-M.
  2. Declare mzTab-profile for the sections the file has, for example M+S+F+E for metadata, summary, features and evidence. Without it, the validator infers the profile and says so (Info-2052).
  3. Remove the fields of sections the file does not have. The validator reports each one (Info-2057). In the editor, {{ previewLabel }} on that message opens the quick fix {{ removeFieldTitle }}, which shows the lines it removes; nothing changes until you apply it (see Use a quick fix).
  4. If you like, describe the factors of the study with study_variable_group: one group for each factor, listing the study variables that are its levels (see Describing your study design). If the file has study_variable[n]-factors, replace them this way: in a 2.1 file the validator warns about them (Warn-2067).
  5. Validate the file again on the start page; a file that declares 2.1.0-M is checked by the 2.1 engine (see Validating 2.1 files).

Validating 2.1 files

The validator reads the mzTab-version of a file and sends a 2.1.0-M file to the engine for mzTab-M 2.1, which checks it with jmzTab-m 2.1. Its default rules for controlled vocabulary terms are the profile mztab-m-2.1-default; the start page offers only the profiles of the file's version.
