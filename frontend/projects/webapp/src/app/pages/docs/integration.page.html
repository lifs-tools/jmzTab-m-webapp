REST API

What the pages of this validator do can also be done by a script, a pipeline or another service, through the REST API under rest/v2. The REST API documentation (Swagger UI) describes every endpoint with its parameters and lets you try them. The main ones:

  • POST rest/v2/validations uploads a file and starts its validation; GET rest/v2/validations/{{ '{' }}id{{ '}' }} returns the status and the messages.
  • POST rest/v2/validatePlain validates a tab-separated mzTab-M file and answers with the messages; POST rest/v2/validate does the same for its JSON representation.
  • POST rest/v2/convertPlain converts a tab-separated file to JSON, and POST rest/v2/convert converts JSON to a tab-separated file.

Results are kept for a limited time, as described in About this service.

Libraries for Python and R

This validator reads files with jmzTab-m, the Java reference implementation of mzTab-M. Its project also has libraries for Python and R, both early development versions:

  • pymzTab-m, for Python 3: a parser for the tab-separated format, the mzTab-M data model and a client for the REST API of this validator.
  • rmzTab-m, for R: the mzTab-M data model and a client for the REST API of this validator.

Which mzTab-M versions each library reads and writes is described in its documentation.

Self-hosting

The validator can run on your own servers: the webapp and one engine for each mzTab-M version, as Docker images or as Java applications. The self-hosting documentation on GitHub describes how to build, configure and operate it.
